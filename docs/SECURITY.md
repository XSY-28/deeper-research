# 数据与安全

运行研究时，问题、候选和需要的资料片段会发送给所配置的模型服务。导入和本地查看不会发起模型请求。确认材料适合该服务后再执行；本工具不是保密资料的隔离环境。

APIkey放环境变量或配置旁.env，向导写入0600；不在任务公开profile里保存key值，也不在报错中输出请求头。向导不联网验证，环境变量会覆盖文件值。避免在聊天、issue、日志或截图中粘贴真实key。

release-files.json是公开候选的精确白名单。Git忽略和源码包清单也按此维护，默认不纳入其他文件。实际config.json、.env、workspace、账本/答案/资料、.work、笔记/交接及evals本地实验规约均保留本地。导出脚本拒绝私密路径、符号链接、常见token/私钥和个人home路径；只打印路径与类别，不回显命中内容，也不会遍历真实.env或workspace。

扫描器是启发式，不能证明所有任意格式的秘密都不存在。只审查和上传干净候选目录；不要git add -f强制加入被排除文件，或直接把整个工作目录/旧Git历史打包。若已有仓库曾提交秘密，.gitignore不能清除历史，需先撤销凭据并另行处理历史。本项目准备步骤不会联网发布。

如发现可能泄露，请先停止传播、撤销相关凭据；不要在公开issue贴秘密或原始私密资料，通过维护者公开的联系渠道告知必要的最小信息。导入的第三方PDF及数据不随代码发布。
