# 能力与验证边界

本项目的定位是人工复核的固定资料研究原型。可交付本地资料/来源/费用记录和single草稿；multi调度、比较与回流有实现，仍是实验功能。

离线测试覆盖不可变来源、来源范围、预算/状态、传输及未知处理、核验契约、保留候选、配置向导和安装入口。模型边界使用脚本替身或本机回环服务，向导使用虚拟key/TEMP/PTY。通过测试不代表真实模型理解、完整loop或答案质量提升。

早期开发暴露过资料窗口丢标题、跨主语误读、正确引用但不支持结论、缺失核验范围和有限调用内不能闭合。结构和来源传递修复不构成确定性蕴含判断。语义仍由模型判断，内部criteria_met必须接受人工复核。

当前未完成稳定的完整同预算独立质量收益验证；提前失败导致的低费用不能称效率优势，少量开发题不能称泛化。公开包不携带本地原始实验数据，也不将历史版本的一次正确答案当成当前版本效果。
